# MGI Fresh | Dealership Management System

A free, installable web app for running a dealership: daily sales sheets (printed in your own paper-form layout), sales history, products and rates, dues (baki), stock, returns and damage, SR / DSR / driver team and salary, reports, Excel and CSV export, backup and restore, optional encryption, and free cloud backup through a private GitHub Gist.

Made for **Foisal Chowdhury Traders** (MGI Fresh dealer). It runs fully in the browser, works offline after the first visit, and keeps all data on your own device. No server and no paid service is needed.

## Run
Open `index.html` in a browser, or host the folder on GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder). Open the link on a phone and choose **Add to Home screen**.

## Files
`index.html`, `style.css`, `app.js`, `storage.js`, `products.js`, `sales.js`, `dashboard.js`, `reports.js`, `business.js`, `ocr.js`, `secure.js`, `cloud.js`, `sw.js`, `manifest.webmanifest`, icons and header images.

## Data and safety
Data is saved in the browser (localStorage). Export a backup file regularly from Settings. Turn on encryption in Settings, Security, if the phone is shared.
